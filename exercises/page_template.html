Local Your Docker server

Set it up once with ./setup.sh from the repo (see its README). Then open the web UI at localhost:8123/play with user admin and the password in your .env file. Datasets: meters, imdb, uk, nyc_taxi.

Exercises 11–15, 31, 32 and 39 build a practice database. If it gets messy, run DROP DATABASE practice and restart at exercise 11.

Browser Public playground

sql.clickhouse.com: read-only, billions of rows. Use it for the exercises marked Browser, including all of module 9 (big data).

The public user can return at most 10,000 rows per query, so every answer here is small.

Local S3 bucket and dbt

Module 10 uses a local S3 bucket (SeaweedFS) holding the meter readings as daily Parquet files, reached in SQL as s3(lake, filename = 'readings/…').

dbt runs in Docker, so no Python is needed: docker compose run --rm dbt build. Your models go in dbt/meter_project/.

Pasting results

Any of these work:

  • select and copy the result grid in the web UI;
  • add FORMAT TSVWithNames to your query and copy the text;
  • copy a Pretty table from clickhouse-client.

Header rows, borders and row numbers are ignored. Numbers only need to match to the rounding the exercise asks for.

Known problems in the data

  • Duplicate rows for the same (meter_id, ts); some have a corrected value. The newest ingested_at wins.
  • Random missing intervals; outages on meter 17 (Feb 10–12) and meter 260 (Mar 5–6).
  • Meters 42 and 230 were replaced at 2026-02-15 00:00 UTC, so their counters restart from 0.
  • Meter 99 has one glitch reading (+5,000 kWh) on 2026-02-20.
  • Some readings arrive up to 5 days late.
  • Local time is Europe/Sarajevo. The clocks move forward on 2026-03-29.

Clean consumption, step by step

  1. Deduplicate: one row per (meter_id, ts), keeping the newest ingested_at.
  2. Drop glitches: a reading whose value is higher than the next reading's, unless the next reading is a replacement.
  3. Delta: value − previous value. The first reading at or after toDateTime(install_date, 'UTC') (the replacement moment, midnight UTC) counts its own value.
  4. Skip each meter's very first reading, because it has nothing to compare with.

Convention used in this course: ts is the end of an interval, and each interval's consumption is counted on the date and hour of its ts. Real billing usually uses the interval start (the reading at 00:00 belongs to the previous day), so check which convention your project uses.
